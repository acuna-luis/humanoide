Misma muñeca, distinta orientación R

El sensor gris y sus ejes permanecen iguales. Sólo cambia cómo está girada la abrazadera azul respecto al sensor. Arrastra cualquiera de las vistas para mirar todas desde el mismo ángulo.

1 · Sin giro: R = identidad

R₁ = [[1, 0, 0],
      [0, 1, 0],
      [0, 0, 1]]

El ancho sigue X y la altura sigue Y. Las patitas naranjas están hacia +X. La marca amarilla identifica el borde superior original.

2 · Un cuarto de vuelta: +90° sobre Z

R₂ = [[0, -1, 0],
      [1,  0, 0],
      [0,  0, 1]]

El ancho pasa hacia +Y y la altura hacia −X. Las mismas patitas quedan hacia +Y. La almohadilla sigue mirando hacia +Z.

3 · Un cuarto de vuelta: +90° sobre X

R₃ = [[1, 0,  0],
      [0, 0, -1],
      [0, 1,  0]]

La almohadilla pasa de mirar hacia +Z a mirar hacia −Y. El borde superior amarillo pasa hacia +Z. Las patitas siguen hacia +X. Es como inclinar la placa alrededor de su dirección de ancho inicial.

4 · Un cuarto de vuelta: +90° sobre Y

R₄ = [[ 0, 0, 1],
      [ 0, 1, 0],
      [-1, 0, 0]]

La almohadilla pasa de mirar hacia +Z a mirar hacia +X. El borde superior sigue hacia +Y. Las patitas pasan hacia −Z. Es como girar la placa alrededor de su dirección de altura inicial.

Cómo leer el signo: los giros son respecto a los ejes fijos del sensor. Para +90°, apunta el pulgar de la mano derecha hacia el eje positivo; los dedos indican el sentido del giro. Cada ejemplo empieza desde la identidad: no se suman los giros entre tarjetas.

Qué hace R: expresa las direcciones de la pieza en los ejes del sensor. Por ejemplo, el punto del útil [40, 0, 80] mm se expresa como [40, 0, 80] mm en el primer caso y [0, 40, 80] mm en el segundo. Con R₃ queda [40, −80, 0] mm; con R₄ queda [80, 0, −40] mm.

Convención: punto_sensor = R × punto_útil + t. Aquí t = [0, 0, 0] mm en los cuatro ejemplos, para aislar el efecto de R. Las columnas de R indican hacia dónde apuntan los ejes X, Y y Z del útil respecto al sensor. La matriz no tiene unidades.

Son montajes ficticios para explicar R, no estimaciones de tus brazos izquierdo/derecho ni instrucciones de giro. Geometría simplificada; no demuestra viabilidad mecánica o ausencia de colisiones. No mueve el robot ni cambia la ficha.
